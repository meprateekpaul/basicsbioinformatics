# CBBI-615: Next-Generation Sequencing (NGS) Data Analysis

**B.Tech. Bioinformatics · Semester VI · 4 (L-T-P 2-0-2)**  
*Department of Computational Biology & Bioinformatics, JSBB, [SHUATS](https://shuats.edu.in/)*

## Overview
High-throughput sequencing workflows: FASTQ quality control (FastQC), short/long-read alignment (BWA, Minimap2), variant discovery (GATK HaplotypeCaller), RNA-seq quantification (DESeq2), and ChIP-seq peak calling.

See the detailed instructional architecture in [COURSE_PLAN.md](COURSE_PLAN.md).
